## NullIp v1.0

Плагин для Minecraft 1.16.5 (Paper), который запрещает игрокам входить на сервер, если их IP не совпадает с указанным в конфиге.

### Возможности
- Привязка ников к IP-адресам
- Блокировка входа при несовпадении IP
- Настраиваемое сообщение кика
- Поддержка `ignore-name-case`
- Перезагрузка конфига через команду

### Команда

```txt
/nullip reload
```

### Конфиг

```yml
settings:
  enabled: true
  ignore-name-case: true
  kick-message: "&cВход запрещён. Этот ник не привязан к вашему IP."

allowed:
  "127.0.0.1":
    - Player
    - Player2
```

### Как работает

При входе игрока плагин проверяет:
1. Включён ли NullIp  
2. Есть ли IP игрока в конфиге  
3. Привязан ли ник к этому IP  

Если проверка не проходит — игрок получает kick с указанным сообщением.
Подходит для приватных серверов с привязкой аккаунтов к IP.
