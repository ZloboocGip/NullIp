## NullIp v1.0

Плагин для Minecraft (Spigot/Paper), который запрещает вход на сервер, если IP игрока не соответствует указанному в конфиге.

### Возможности
- Привязка ников к IP-адресам
- Блокировка входа при несовпадении IP
- Настраиваемое сообщение кика
- Поддержка ignore case для ников
- Перезагрузка конфига через команду

### Команда
```txt
/nullip reload
